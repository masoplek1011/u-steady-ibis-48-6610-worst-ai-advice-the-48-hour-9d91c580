A one-line entry for the "Worst AI Advice" open: the worst possible advice an AI assistant could give, in 140 characters or fewer — confident, tidy, concrete, and regrettable if followed. The program writes that single line to `entry.txt`.

## Run it

```sh
node main.ts
```

By default the line is written to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to choose another directory.
